# Picarto (ピカルト) コメント連携プラグイン for わんコメ

[わんコメ（OneComme）](https://onecomme.com/) に、イラスト・アート系配信プラットフォーム [Picarto.tv](https://picarto.tv/) のライブ配信チャットコメントをリアルタイムに取り込むプラグインです。

Picarto公式のREST APIおよびWebSocketプロトコルに準拠し、Pure Node.js（外部ライブラリ非依存）で動作します。

---

## 主な特徴

- **ゼロ外部依存（Pure Node.js）**: `npm install` や外部モジュール不要。単体ファイルで確実に動作します。
- **公式API準拠のセキュア接続**: SSL/TLS経由のWebSocket通信で低遅延にコメントを受信。
- **内包設定画面（Web UI）付属**: わんコメのプラグイン画面から直感的にチャンネル名やトークンの設定、接続ステータス（待機中 / 配信中 / 受信中）の確認が可能。
- **アバター画像・配信者フラグ完全対応**: コメント投稿者のアバターアイコンや配信者本人の発言を自動識別してわんコメへ反映。
- **内蔵ブラウザ自動保護**: 誤って枠URLが設定された場合でも、わんコメ内蔵ブラウザのエラーによる自動OFFを防止して常時安定稼働。

## 導入手順

### 1. ダウンロードと配置
1. 本リポジトリ右上の **「Code」→「Download ZIP」** からZIPをダウンロードして解凍します。
2. わんコメを開き、左上の **メニュー「≡」→「連携」→「プラグイン」** を開きます。
3. **「フォルダを開く」** をクリックします（`%APPDATA%\onecomme\plugins` が開きます）。
4. 解凍したフォルダ（フォルダ名を `picarto` に変更推奨）を配置します。

フォルダ構成のイメージ:
```text
plugins/
  picarto/
    plugin.js
    index.html
    config.sample.json
    package.json
    README.md
    LICENSE
```

### 2. わんコメ側で枠を追加
1. わんコメの「配信」または「視聴者」一覧の **「＋」** ボタンから枠を作成します。
2. 枠の名前を **`Picarto`**（または `#Picarto`）に設定します。
3. **URL欄は空欄（空白）のままでOK**です。
4. 枠のスイッチを **ON（有効）** にします。

### 3. プラグイン設定
1. わんコメの「連携」→「プラグイン」一覧で、Picartoプラグインの **「設定」** ボタンを押します（ブラウザで内包設定画面が開きます）。
2. **Picarto チャンネル名**（例: `orangeqoon`）を入力します。
3. （推奨）[Picarto公式ボットトークン発行ページ](https://oauth.picarto.tv/chat/bot) にログインして発行したOAuthトークンを入力します。
4. **「設定を保存して接続」** をクリックします。

---

## 仕様・通信について

- **チャット受信**: `wss://chat.picarto.tv/`
- **配信状態確認**: `https://api.picarto.tv/api/v1/channel/name/{channel}`
- **わんコメ連携**: わんコメ標準ローカルAPI（`http://localhost:11180/api/comments`）を経由して指定枠へ中継します。
